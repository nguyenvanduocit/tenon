Findings ưu tiên

CriticalT-091: SwiftUI update loop đã gây 100% CPU / 11 GB, root cause và regression test vẫn mở

Live process sample chứng minh một lazy-layout prefetch cycle không hội tụ trong NSHostingView. Việc bỏ sizing options là correction đúng intent nhưng task tự ghi rõ chưa phải proven fix.

T-091 lines 19–99, 120–139; real Agent Lens trigger chưa tái hiện ở lines 141–152.

Release gate: tái hiện trên real app + live agent, instrument update turns, xác định root, thêm bound regression. Hoàn tất T-092 diagnostics để lần spin tiếp theo tạo receipt sớm; không coi sizing-options change hay telemetry là resolution.

HighPlugin shutdown timeout không bao phủ đoạn có thể treo

shutdown(timeout:) chỉ đưa timeout vào executor sau prepareForShutdown, callback pump, invocation drain và state emitter. Synchronous runaway JS có thể giữ pinned executor trước khi deadline bắt đầu.

PluginRuntime.swift:479–498, 565–639; PluginHost.swift:2288–2306.

Fix: global deadline cho toàn state machine; JS execution watchdog/interrupt hoặc process isolation; concurrent retirement dưới một bounded deadline; test bằng helper subprocess.

HighEVENT host task vẫn bị observer chi phối, tạo cross-plugin head-of-line blocking

JavaScript tenon.events.emit trả về ngay, nhưng publisher generation giữ một pending host task cho tới khi PluginHost.publish await tuần tự từng runtime.emit. Observer chậm/runaway vì thế vẫn điều khiển publisher backpressure, shutdown và thứ tự plugin sau.

Boundary law: lines 530–534, 767–777; PluginHost.swift:1869–1974.

Fix: bounded mailbox riêng cho mỗi runtime generation; publish = validate/enqueue/return; định nghĩa capacity, overflow/coalescing, retirement và terminal state.

HighCLI cap 8 chỉ giữ decode phase, không giữ toàn physical request lifetime

Semaphore được nhả khi closure đã post lên MainActor, trong khi FD và async intent reply còn sống. Flood valid slow requests có thể tăng FD/tasks/main-queue không giới hạn.

CLISocketServer.swift:37–39, 426–519.

Fix: permit sở hữu FD đến terminal close, once-settlement guard, bounded queued+executing+replying, fail-fast busy, track/cancel tasks khi stop.

HighMain scene cho phép nhiều window nhưng composition/surface resources là singleton

WindowGroup dùng một AppComposition; SurfacePool chỉ có một surface/slot và Ghostty trả cùng NSView. New Window có thể reparent terminal view khỏi window đầu, trái one-window product contract.

TenonApp.swift:12–22; SurfacePool.swift:86–90; GhosttySurface.swift:1363–1366.

Fix: dùng singleton Window("Tenon", id: "main") hoặc replace New Window semantics; UI test pin đúng một main window.

HighExternal plugin contribution có thể ghi đè text draft đang được nhập

Mọi external value change ghi đè @State draft kể cả khi field focused. Cùng repo đã có implementation focus-safe cho pane header, nên đây là behavior gap có fix pattern rõ.

BuiltInSlotViews.swift:520–537; đối chiếu PaneHeaderBar.swift:267–302.

Fix: focus/dirty rule; test plugin republish trong lúc user gõ và external value apply sau blur.

MajorAgent Hook live ingestion chưa áp dụng cùng live-process validation như discovery

Exact pane/surface token là lớp binding thứ hai nên global bearer một mình chưa tạo exploit. Tuy vậy, live ingestion vẫn project provider/PGID do client khai báo mà không revalidate foreground process như transcript discovery path; integrity risk còn thật nhưng confidence về exploit là medium.

AgentSessionHooks.swift:239–270, 332–358, 682–735; AgentLensSession.swift:364–393.

Fix: một actor validate foreground PGID/provider ancestry/root session rồi atomically record+publish; credential per-surface, rotate theo incarnation.

HighBlocking DNS resolve nằm ngoài cancellation/deadline

getaddrinfo chạy trong detached task, không cooperative; transport timeout tính trước DNS và không recompute remaining time sau resolve.

NetworkIntentProvider.swift:103–163, 295–390.

Fix: cancellable/bounded resolver ownership; recheck cancellation/deadline sau resolve và recompute transport timeout; barrier test với injected blocked resolver.

MajorPluginHost là five-domain god coordinator mà chính repo đã đánh dấu split candidate

3,182 lines, five domains và co-change rộng. Đây là finding cohesion rõ hơn mọi generic “class nên nhỏ”.

PluginHost.swift:1–6, 352–358; domains.md:36–38.

Fix: giữ PluginHost façade/atomic generation commit; extract lifecycle inventory, administration/settings/storage, contribution projection, event router và presentation index bằng typed DIRECT calls.

MajorIntentDispatcher.send là transaction script ~1,176 lines

Một actor method điều phối admission, causality, consent, idempotency, provider invocation và settlement. Single semantic entry là đúng; single physical function thì khó audit terminal path.

IntentDispatcher.swift:312–1491.

Fix: typed phase values như Admission/Authorization/Invocation/Settlement; actor-owned collaborators chỉ khi chúng có invariant riêng; giữ một public send, không thêm handwritten command API.

MajorSpatialCanvasView.swift trộn pure interaction, SwiftUI bridge, AppKit hosting và accessibility

2,495 lines / 18 nominal types; coordinator, representable, NSView, drag overlays, content host, card và controls có lifecycle khác nhau.

SpatialCanvasView.swift:73, 403, 474, 1599, 1680, 1689, 2466.

Fix: split thành feature folder trong cùng target; types internal/private; preserve identity and behavior; regression tests trước move.

MediumSwift library products và access control chưa nói rõ supported API

Package export TenonCore/TenonIntentCore trong khi comment nói app không phải versioned dependency; lexical scan có ≥1,470 public declarations/members, nhưng extension surface thật là JS intents/contributions.

Package.swift:4–21; package access đã dùng tại PluginHost.swift:333–347.

Decision: nếu internal, bỏ library products và migrate cross-target API sang package; nếu SDK, định nghĩa SemVer/docs/symbol graph. Thêm API surface baseline.

MediumDomain fitness ratchet chưa đạt normative “every source file”

141 file chưa tag vẫn pass vì test là ratchet; 48 file chưa tag dài hơn 400 lines. Đây là governance debt P0, không phải runtime blocker.

domains.md:20–38; DomainTagFitnessTests.swift:16–20, 86–100.

Fix: tag theo coherent batches + mandatory symbol-edge traversal, hạ budget mỗi batch tới 0; file mới vẫn phải tag ngay.

MajorSync filesystem/process work còn nằm trên UI ownership path

CLI installer/file checks, recent persistence và một số Git subprocess logic chạy từ view/MainActor. Nó vừa tạo hitch risk vừa để isolation chỉ là convention.

SettingsView.swift:167–235; CLICommandInstaller.swift:23–75; Git duplication ở DiffSlotView.swift:156–250 và ChangesPanelView.swift:239–343.

Fix: typed DIRECT services + persistence actor/serial writer; MainActor chỉ publish observable snapshot; coalesce/version writes.

MajorCustom plugin modal thiếu native modality/focus/accessibility semantics

Overlay tự vẽ chưa trap/own initial focus, chưa ẩn background khỏi accessibility tree, chưa có modal AX semantics và close icon thiếu spoken label.

PluginModalOverlay.swift:41–86.

Fix: ưu tiên native .sheet(item:); nếu custom, implement AX modal/focus/keyboard isolation/restore và regression test với terminal background.

MajorNative integration/UI suites chưa chạy trong CI

CI chạy swift test và Xcode build, nhưng không execute 6 integration + 9 UI tests chỉ có trong Xcode scheme. Repowise cũng chưa có coverage map nên “untested hotspot” là unknown, không phải chứng cứ thiếu test.

macos-ci.yml:42–54; project.yml:197–250.

Fix: IntegrationTests trên PR; UI smoke ở dedicated GUI lane/nightly với xcresult/screenshots/AX hierarchy/logs; ingest coverage map.

MediumStateful plugin nodes dùng offset identity nhưng chưa có reproduction

Recursive ForEach(..., id: \.offset) có thể chuyển draft/focus khi sibling insert/reorder, nhưng schema chưa có stable general node ID và audit chưa tái hiện lỗi. Đây là focused schema/test item, không phải HIGH defect đã chứng minh.

BuiltInSlotViews.swift:704.

Fix: dựng red test reorder trước; nếu cần node ID, cập nhật CONTRIBUTION inventory, schema, parser, docs và fitness tests trong cùng change.

MediumSlot accessibility value đang mang test/debug metadata

VoiceOver nhận raw UUID/grid internals thay vì pane title, state và vị trí dễ hiểu. Đây là accessibility defect thật nhưng thấp hơn modal/focus failure.

SpatialCanvasView.swift:1746–1758, 2399.

Fix: semantic label/value cho người dùng; test dùng stable identifier riêng thay vì chiếm AX value.

MediumDesign/accessibility/localization còn drift

Settings dùng decorative feature palettes trái design law; header contract 31pt nhưng runtime token 34pt; attention chủ yếu truyền bằng màu; icon-only shell buttons thiếu AX label; chưa có String Catalog/locale-aware search.

designs.md:47–67, 94–98, 153–155; SettingsView.swift:27–101; TenonTheme.swift:52–74.

Fix: sau correctness: reconcile tokens, add semantic spoken state + Differentiate Without Color, String Catalog, LocalizedStringResource, locale-aware format/search.

Definition of done và guardrails đề xuất

Correctness receipts

  • Runaway plugin helper cannot block quit/reload beyond declared deadline.
  • EVENT publisher returns after bounded enqueue; slow observer cannot block another plugin.
  • CLI physical in-flight FD/request count never exceeds configured cap.
  • DNS cancellation/deadline test proves no stale transport starts.
  • Only one main window; no view reparenting.
  • Plugin draft/focus survives republish and reorder with stable identity.
  • T-091 has real repro, root explanation and red/green bound test.

Structural guardrails (team targets, không phải luật Swift)

  • Untagged source budget = 0; tối đa 2 domain tags/file trước khi split review.
  • Coordinator >800 lines hoặc function >150 lines cần documented exception/review.
  • No stateful ForEach identity theo index/offset.
  • No synchronous filesystem/subprocess work on MainActor.
  • Public/package surface có symbol-graph baseline và intentional diff.
  • swift test, focused fitness, XcodeGen diff, app build và native test lane đều xanh.

Anti-goals

  • Không big-bang rewrite hoặc “module per feature”.
  • Không tạo intent giữa built-in SwiftUI/AppKit và same-owner application services.
  • Không thêm protocol cho mọi collaborator chỉ để mock; dùng value/pure function hoặc concrete actor trước.
  • Không blanket @MainActor, @unchecked Sendable hay Task.detached để dập compiler warning.
  • Không chia canonical intent inventory hoặc pure workspace rules chỉ để đạt line-count đẹp.
  • Không làm cosmetic modernization trước P0 liveness/correctness.
