Blocking findings

Blocker · high

Generated Xcode project is stale, so CI will fail before tests

poc/Tenon.xcodeproj/project.pbxproj:900 omits ChangesRowPlanTests.swift, ScrollbarStyleTests.swift, and TreeRowItemTests.swift. CI regenerates the project and runs git diff --exit-code at .github/workflows/macos-ci.yml:37. A clean temp generation changed the project by 27 insertions / 15 deletions and added all three files.

Fix: run xcodegen generate from poc/ and commit the complete generated-project diff.

Blocker · high

One process group does not prove “idle shell”

poc/Sources/TenonCore/TerminalJobTermination.swift:74–99 returns .idle whenever a terminal has one PGID. An exec codex-style replacement preserves the shell PID/PGID, and job-control-disabled children can share that PGID. The new test at TerminalJobTerminationTests.swift:121 explicitly treats an additional same-group process as idle.

This violates the documented fail-safe rule and can close active work without confirmation.

Fix: retain the original shell identity (PID plus executable/start identity), prove it is still the shell, and classify every unrecognized same-group process as running or unavailable. Add exec and job-control-disabled fixtures.

Blocker · high

An old idle result can close a newly changed tab

poc/Sources/TenonApp/ShellTitleBar.swift:96–137 snapshots terminal PIDs before await inspect. After suspension, it checks the request UUID and only whether the tab still exists; it does not compare slot membership, surface incarnation, or current foreground PIDs.

A terminal can be added, replaced, or become busy during the process-table read, then be destroyed by the stale idle result.

Fix: snapshot identities keyed by slot and surface token, re-snapshot after the await, and act only on exact equality. Otherwise confirm as unavailable or restart inspection. Extract an injected close coordinator and test identity mutation plus request supersession.

Blocker · high

The new row-list domain does not retrieve what it says it owns

rg -l '@domain:.*row-list' poc/Sources returns only TreeRowsView.swift. Mandatory symbol-edge traversal finds the vocabulary in PluginRuntimeModels.swift:41, decoder in PluginRuntimeValueParsing.swift:31, and native planner in ChangesPanelView.swift:355, all untagged for row-list. This contradicts docs/domains.md:137.

Fix: preferably extract the vocabulary, decoder, and plan into focused tagged files. At minimum tag every genuinely owned file/section and satisfy the over-400-line MARK rule; then lower the untagged budget for newly tagged files.

Major · high

A transient single-file read failure uninstalls the active plugin

poc/Sources/TenonCore/PluginHost.swift:786–800 uses try? to read a single-file plugin and handles a read error as “manifest header is gone,” uninstalling an existing session. That contradicts the method contract at line 736 that a failed candidate never replaces the active session.

The claimed watcher-path test at SingleFilePluginTests.swift:51–80 edits the file and then calls loadAll(); it never exercises reload(directoryNamed:) or FSEvents.

Fix: distinguish read failure from a successfully read header removal. Preserve the active generation on I/O/decode failure, and add exact reload plus watcher-path regressions.

Major · high

Public row detail is not bounded by the row contract

TreeRowItem.detail is stored verbatim at PluginRuntimeModels.swift:85,100–114 and decoded verbatim at PluginRuntimeValueParsing.swift:47. The generic 64 KiB IntentValue ceiling is not a row-specific bound and does not constrain host-native Swift construction. T-085 explicitly requires both new public values to be bounded at lines 45–48.

Fix: introduce a source-owned detail maximum in TreeRowItem or a bounded value type. Drop or truncate only the detail, and test overlong/empty/non-string input.

Major · high

Changes selection is visual-only for accessibility

TreeRowsView.swift:106–170 expresses selection only through color/background. The row button has no selected trait or value; ChangesRowPlanTests.swift:191 proves only the model bit. The newly advertised selection state is therefore not exposed to assistive technology.

Fix: make the row one coherent accessibility element, conditionally add .isSelected, expose expanded/collapsed and useful status meaning, hide decorative glyphs, and add a hosted accessibility-tree receipt.
