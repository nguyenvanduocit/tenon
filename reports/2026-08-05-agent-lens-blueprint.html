Recommendation / Hybrid, capability-driven

Đừng biến terminal thành chat. Hãy đặt một Agent Lens lên cùng session.

Tenon nên cho người dùng một giao diện hội thoại thống nhất, nhưng không lấy giao diện đó làm runtime mới. PTY vẫn chạy agent thật; một lớp projection đọc semantic events từ protocol, transcript và hook, rồi render chúng thành Conversation, Activity và Attention UI.

Giải pháp đề xuất: Conversation là chế độ mặc định cho agent session; Terminal là escape hatch luôn có thể quay lại. Cùng một slot, cùng một process, cùng một lịch sử—không restart, không replay, không giả lập TUI.

Kiến trúc: Agent Lens là projection cùng slot

Không thêm SlotContent.chat. Một terminal slot có thể có hoặc không có một AgentPresentationSession. Surface pool giữ execution; session pool giữ semantic projection; SwiftUI chọn renderer.

Invariant quan trọng nhất: terminal là nguồn sự thật về execution; semantic event stream là nguồn sự thật về presentation. UI không suy diễn tool call, approval hay completion từ pixel.

Session correlation, không đoán filename

Tenon-launched session mang descriptor chính xác. Session chạy thủ công được nối bằng hook kế thừa TENON_PANE_ID, provider session ID, cwd và process identity. Scan “file mới nhất” chỉ là recovery, không là identity rule.

Managed hooks phải merge cấu hình có namespace, backup, rollback và không ghi đè hook của user.

Canonical model: event log nhỏ, reducer thuần, snapshot ổn định

Domain events
enum ConversationEvent: Sendable {
  case turnStarted(TurnID, EvidenceAnchor)
  case userMessage(Message)
  case assistantDelta(MessageID, TextDelta)
  case assistantMessage(Message)
  case reasoning(ReasoningBlock)
  case toolStarted(ToolRun)
  case toolUpdated(ToolRunID, ToolDelta)
  case toolFinished(ToolReceipt)
  case question(InteractionRequest)
  case approval(ApprovalRequest)
  case artifact(ArtifactReference)
  case status(SessionStatus)
  case diagnostic(AdapterDiagnostic)
  case turnFinished(TurnReceipt)
}
Required metadata
  • Stable ID: provider ID khi có; deterministic derived ID khi không.
  • Cursor + revision: ordering và replacement không phụ thuộc array index.
  • Provenance: source kind, location, byte/range, hash, captured-at.
  • Authority: reported claim khác verified observation.
  • Confidence: native, transcript, hook, inferred, degraded.
  • Freshness: current, superseded, stale, source-missing.
Không persist UI tree. Persist event cursor, source identity và lightweight snapshot. Khi schema adapter đổi, replay bounded events hoặc rebuild từ transcript; raw source không bị copy thành một database “sự thật” thứ hai.

Swift 6 design: actor ownership rõ, MainActor nhẹ

Repo đang ở Swift language mode 6, macOS 14 và warnings-as-errors. Thiết kế phải Sendable-clean ngay từ đầu; không dựa vào implicit main-actor isolation hay Task.detached.

Ownership

AgentSessionCoordinator actor

Sở hữu adapter task, cursor, reducer state, optimistic sends và reconciliation. Một actor cho một session để tránh contention giữa panes.

Transport

AsyncThrowingStream

Adapter trả stream có cancellation và terminal state. Tool/status lane bounded; message/receipt lane không drop.

Presentation

@MainActor @Observable

Chỉ nhận immutable snapshots đã coalesce. Không đẩy từng byte token qua Observation graph.

Backpressure có chính sách

  • Assistant delta coalesce khoảng 30–60 Hz.
  • Status mới thay status cũ chưa render.
  • Không drop user message, final message, approval, tool receipt.
  • Tool output lớn trở thành bounded artifact/resource, row chỉ giữ summary.
  • Overflow sinh diagnostic rõ ràng, không im lặng mất dữ liệu.

Lifetime có cấu trúc

  • Session task bắt đầu khi Agent Lens attach.
  • Unmount UI không giết PTY; detach lens hủy watch/tasks.
  • Slot close hủy coordinator và giải phóng adapter resources.
  • Long-running tasks dùng cancellation + weak ownership đúng chỗ.
  • Test dùng injected clock/stream; không sleep để đợi race.
SwiftUI rendering: ScrollView + LazyVStack, stable IDs, per-row state hẹp; autoscroll chỉ khi user đang gần đáy; khi user đọc phía trên, hiện “N updates” thay vì giật viewport. Terminal view có thể detach để Ghostty tự occlude renderer trong khi PTY tiếp tục sống.

Trust model: đẹp nhưng không được tạo overconfidence

Evidence

Claim không tự biến thành fact

“Tests passed” trong assistant text là reported claim. Chỉ command/test receipt có exit status và anchor mới được badge Verified.

Ingestion

Transcript là untrusted input

Path phải được resolver cấp, canonicalize và scope theo provider/session. Giới hạn record size, depth, output, attachment và render URL.

Summaries

Không chạy với ambient authority

Nếu dùng model để nén context, broker read-only nhận evidence bundle tối thiểu; output là candidate và bắt buộc resolve exact anchors.

Degradation

Thất bại phải lộ ra

Adapter lag, malformed JSON, lost hook và cursor gap đều thành diagnostic + freshness state; Conversation không âm thầm đứng yên.

Rollout: ship một wedge nhỏ nhưng đúng trục

Phase 0 — Read-only spike · 1–2 tuầnClaude + Codex transcript decoders, fixture corpus, static Conversation preview; chưa hook, chưa composer.
Phase 1 — Same-slot Agent Lens · 2–3 tuầnDetection, managed hook correlation, Conversation/Terminal toggle, live updates, degraded state, per-slot lifetime.
Phase 2 — Safe steering · 2 tuầnPTY input queue, optimistic user message + reconciliation, questions/approvals cards khi source đủ mạnh.
Phase 3 — Attention layer · 2–3 tuầnneeds-input, failed, ready-for-review, completed; exact re-entry và evidence anchors.
Phase 4 — Protocol-native adapterCodex/app-server hoặc provider protocol ổn định; UI giữ nguyên, chỉ adapter/capabilities thay đổi.
Phase 5 — Public extensibility, chỉ nếu có nhu cầu thậtNormative inventory, contribution/resource contracts, security review và architecture fitness tests trong cùng change.
Vertical slice nên chọn: một Claude hoặc Codex process chạy thật trong libghostty; attach đúng session; render user/assistant/tool; send một follow-up; toggle về terminal không mất state; kill/close không leak watch task.

Release gates: correctness trước độ bóng

Engineering gates

  • Golden fixtures theo provider/version, gồm malformed/partial/huge records.
  • Reducer replay deterministic; duplicate/out-of-order events không đổi final snapshot.
  • Cancellation và deallocation tests cho slot close, tab switch, app termination.
  • Backpressure tests chứng minh receipt/approval không bị drop.
  • UI performance: streaming không gây body invalidation toàn transcript.
  • Accessibility: VoiceOver order, keyboard-only mode switch, reduced motion, contrast.

Product gates

  • Giảm ≥30% median time để user tái định hướng.
  • Traceability error = 0 cho material claims.
  • False-attention items <10%.
  • Send success và reconciliation success được đo theo adapter tier.
  • Terminal-switch rate: đo vì sao user phải thoát Conversation.
  • Outcome quality không giảm khi số workstreams tăng.
North-star metric: verified outcomes per minute of human attention—not message count, token count hay số agent đang mở.

Decision log / non-negotiables

Same slot, same PTY.

Conversation là presentation mode, không là content/runtime mới.

Capability-driven.

UI render theo năng lực được negotiate, không theo chuỗi if provider == ... rải khắp views.

Protocol/transcript first, pixels last.

Screen parsing không có quyền tạo semantic fact.

Evidence is reversible.

Mọi claim quan trọng quay về exact source, hash và freshness.

No public API in MVP.

Host-internal DIRECT + RESOURCE/STREAM đủ để validate product trước khi mở platform surface.

Graceful degradation is a feature.

Agent lạ vẫn là terminal tốt; adapter lỗi không làm process lỗi theo.

Attention beats decoration.

Tool folding, approvals, failures và re-entry quan trọng hơn bubble styling.

Không làm trong MVP

Universal TUI parser

Không thể có semantics bền vững từ ANSI/pixel của nhiều app và nhiều version.

AI-generated truth

Summary không thay thế event, receipt hoặc evidence anchor.

Plugin API tổng quát

Chưa có product proof thì chưa gánh public lifecycle, capability và security contract.

Model/settings parity

Chỉ expose control khi provider adapter có typed capability, không keyboard-drive menu.

Terminal replacement

Power users, unknown commands và recovery luôn cần raw surface.

Unbounded logs

Large outputs thành artifact/resource; transcript rows giữ compact summary.

Repo fit / evidence đã kiểm tra

Tenon: Swift 6 + macOS 14 + warnings-as-errors trong poc/Package.swift; terminal surface được giữ theo slot trong SurfacePool.swift; GhosttyNSView occlude renderer khi detach nhưng giữ PTY/scrollback; BuiltInSlotContentView hiện render terminal trực tiếp; interaction classification theo docs/architecture-interaction-boundaries.md.

Orca: overlay trong TerminalPane.tsx; normalized model trong native-chat-types.ts; provider decoders + transcript watch; live session preview và PTY send path. Kết luận: Orca là PTY harness có semantic transcript projection, không phải TUI-to-chat pixel renderer.

Product research: docs/research-human-agent-supervision.md đã chọn human-attention, evidence-linked context và exact re-entry làm wedge; blueprint này biến direction đó thành same-slot conversation architecture.

Recommendation: ship Agent Lens as a host-internal, same-slot projection; prove Claude/Codex value first; only then standardize a public adapter contract.
