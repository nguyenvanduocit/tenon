# T-177: The chrome a supervisor reads sits where they are looking

> An app preference swaps the title bar's tab strip with the foot's status strip, so the
> tabs land next to the agent output a person actually watches — the whole strip moves,
> pixels and pointer behaviour included, not just its functions.

- **priority**: high
- **effort**: M
- **PRD**: `TENON-PRD-001` workspace-shell (`WS-FR-035`, `WS-NFR-012`), `TENON-PRD-004` settings
  (`SET-FR-035`)

## Why

Supervising parallel agents means reading the bottom of a pane — the newest output — for
minutes at a time. Every tab switch and every `+` then costs a full-window eye travel to a
row 36 pt from the top. The operator asked for the swap explicitly, and scoped the first
step to the tab strip and the status strip only; the identity zone, resource monitor and
quick commands stay in the title bar until a later task moves them.

## Criteria

- [ ] A single app preference names the order; `tabsOnTop` is the default and the stored
      value survives a relaunch.
- [ ] `tabsOnBottom` draws the tab strip in the foot row and the plugin status items in the
      title bar's content zone. Nothing else moves.
- [ ] The strip renders identically in both positions: chip metrics, attention dot, close
      control, hover, drop-target outline, `+` launcher.
- [ ] The strip behaves identically in both positions: click selects, click on ✕ closes,
      six points of travel reorders, an out-of-band release restores the origin index,
      right-click opens the tab launcher, VoiceOver move actions announce the landing.
- [ ] The launcher popover opens away from the window edge the strip sits on.
- [ ] The title bar keeps a window-drag region in both orders; the foot row never claims one.
- [ ] `router.tabBarBand` and the per-chip drop frames follow the strip, so dragging a pane
      onto the strip still makes a tab wherever the strip is.
- [ ] One implementation of the strip. No second code path, no placement-only duplicate view.
- [ ] The placement rule is asserted in `TenonCoreTests` without a window.
- [ ] `TENON_TITLEBAR_SNAPSHOT` can photograph both orders.
